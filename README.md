Jeoplit is a web application that allows users to scrape a Quizlet set and transform it into a Jeopardy-styled game. This project aims to bring an educational twist to the classic Jeopardy format, making learning both interactive and fun.

## Features

- Quizlet Integration: Quickly scrape Quizlet sets to import questions and answers.
- Jeopardy Game Format: Automatically structures the imported data into a Jeopardy-style game board.
- User-Friendly Interface: Built with a combination of EJS, JavaScript, and CSS for an interactive and visually appealing experience.

## Technology Stack

This project utilizes the following technologies:

- EJS (50%): Templating engine for rendering dynamic web pages.
- JavaScript (35.4%): Core logic for game functionality and interactivity.
- CSS (14.6%): Styling to create a clean and responsive user interface.

## Usage

- Enter a Quizlet set URL in the input field provided.
- Let Jeoplit scrape the Quizlet set and generate a Jeopardy-styled game.
- Play and enjoy the game with your friends or use it as a fun learning tool!
